# ⚾ 히팅카운트

Python과 `pygame-ce` 라이브러리를 활용하여 개발한 **탑다운 시점 야구 타격 게임**입니다.

타이밍 게이지에 맞춰 스윙하고, 안타·홈런·볼넷·수비 플레이를 즐기는 것이 목표입니다.
**1인 타격 챌린지**와 **2인 투수 vs 타자 대전** 두 가지 모드를 제공하며,
라인스코어 전광판, 주자·아웃·볼넷 규칙, 병살·희생플라이·끝내기, BEST PLAYER 등 실제 야구에 가까운 연출을 구현했습니다.

---

## 🎯 게임 소개

**히팅카운트**는 Python과 `pygame-ce`로 만든 2D 야구 타격 게임입니다.

하늘에서 내려다본 부채꼴 야구장 위에서 타이밍에 맞춰 스윙하고,
내야·외야 수비, 송구 애니메이션, 결과 배너, 이닝교대, 경기 종료 화면까지 한 화면에서 진행됩니다.

- **1인 모드**: CPU 투수와 대결하며 라운드별 목표 점수를 달성하는 타격 챌린지
- **2인 모드**: 한 명은 구종 선택(투수), 한 명은 스페이스바 타격(타자) — 9회 정규 이닝 대전

## ✨ 주요 기능

### 🎮 2가지 게임 모드

| 모드 | 설명 |
|------|------|
| **1인 게임 (타격 챌린지)** | 제한 아웃 안에 누적 목표 점수 달성, 라운드 클리어 시 난이도 상승 |
| **2인 게임 (투수 vs 타자)** | 9회 정규 이닝, 연장 없음, 동점 시 무승부 / 홈팀 끝내기 승리 |

### ⏱ 타이밍 게이지 타격

스페이스바로 게이지를 멈추면 타구 품질이 결정됩니다.

| 구간 | 범위 | 결과 |
|------|------|------|
| 파랑 | 0~58% | 헛스윙 → 스트라이크 |
| 초록 (HIT) | 58~72% | 기본 컨택·안타 |
| 주황 | 72~82% | 강한 컨택·장타 |
| 빨강 | 82~85% | 최강·홈런 노리기 (가장 좁음) |
| 노랑 | 85~100% | 늦은 스윙·약한 타구 |

구속이 빠를수록 게이지도 빨라집니다. (패스트볼 > 슬라이더 > 커브)

### ⚾ 구종 & 구속 (km/h)

| 구종 | 구속 범위 | 투구 키 (2인) |
|------|-----------|---------------|
| 패스트볼 | 145~153 | A팀 `1` / B팀 `8` |
| 슬라이더 | 125~132 | A팀 `2` / B팀 `9` |
| 커브 | 112~123 | A팀 `3` / B팀 `0` |

같은 구종이라도 매 투구마다 구속이 조금씩 달라집니다.

### 🏃 주자·볼넷·수비 규칙

- **볼넷**: 포스 진루, 만루 볼넷은 **밀어내기** (+1득점)
- **병살타**: 2아웃, 만루 병살 시 3루 득점 (3아웃 이닝 종료 시 그 플레이 득점 무효)
- **희생플라이·태그업**: 2아웃 전 3루·2루 진루
- **2·3루만 있을 때 1루 송구**: 주자 제자리
- **1루 주자 + 2루 포스 아웃**: 3루 주자 홈인 가능
- **실책**: 내야 땅볼 처리 중 확률 발생

### 📊 1인 모드 — 타격 챌린지

| 항목 | 내용 |
|------|------|
| 안타 점수 | 1루타 30 / 2루타 50 / 3루타 70 / 홈런 100 |
| 타점 보너스 | 득점 1점당 +50 |
| 1라운드 목표 | 300점 (누적) |
| 라운드 상승 | +400 → +500 → +600 … |
| 시작 아웃 | 10개 (라운드마다 1개 감소, 최소 5) |

### 🏆 2인 모드 — 9회 경기

- 9회까지 진행, **연장 없음**
- 9회초 후 홈팀이 이기면 **9회말 생략·즉시 종료**
- 9회말 홈팀이 1점이라도 앞서면 **끝내기 승리**
- 9회말 종료 시 동점이면 **무승부**
- 경기 종료 후 **BEST PLAYER** (승리팀 MVP) 표시

### ⏸ 일시정지

- 우하단 **일시정지** 버튼 또는 `ESC`
- **계속하기** / **그만하기** 선택

## 🕹 조작 방법

| 키 | 기능 |
|----|------|
| `Space` | 타격 (타이밍 게이지 멈추기) |
| `1` / `2` / `3` | A팀(원정) 구종 선택 |
| `8` / `9` / `0` | B팀(홈) 구종 선택 |
| `ESC` | 일시정지 |
| `↑` / `↓` / 마우스 휠 | 게임 설명 스크롤 |
| 마우스 | 메뉴·버튼·이름 입력 클릭 |

## 🧠 모듈 구조

### `App` (`app.py`)

게임 루프와 화면(씬) 전환을 담당합니다.

- 메뉴 / 라인업 / 플레이 / 게임오버 / 도움말 / 개발정보
- 입력 처리 · 렌더링 · 씬 전환

### `LiveGame` (`gamestate.py`)

경기 상태와 야구 규칙을 담당합니다.

- 라인스코어 · 주자 · 아웃 · 득점
- 볼넷·병살·희생플라이·끝내기 판정
- 1인 챌린지 점수·라운드·아웃
- 타구 물리·수비 판정 (`resolve_batted_ball`)

### `field.py`

탑다운 야구장 렌더링과 좌표 변환을 담당합니다.

- 부채꼴 그라운드 · 관중석 · 담장 · 파울 폴
- 수비수·타자·주자·공 애니메이션

### `ui.py` / `assets.py`

- 버튼 · 텍스트 입력 · 한글 폰트
- 타이틀 실루엣 이미지

### `config.py`

색상 · 규칙 상수 · 기본 라인업 · 버전 정보

## ▶ 실행 방법

### 1. 프로젝트 폴더 이동

```bash
cd BaseballGame
```

### 2. 가상환경 생성 및 패키지 설치

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 실행

```bash
python main.py
```
